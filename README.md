## HQC-KEM 中的乘法调用
| 操作       | 内部调用                   | 多项式乘法                               |
| ---------- | -------------------------- | ---------------------------------------- |
| KEM KeyGen | PKE KeyGen                 | $(h\cdot y)$                             |
| KEM Encaps | PKE Encrypt                | $(h\cdot r_2,\ s\cdot r_2)$              |
| KEM Decaps | PKE Decrypt + 重新 Encrypt | $(u\cdot y,\ h\cdot r_2',\ s\cdot r_2')$ |

## 乘法操作数类型
| 乘法          | 左操作数   | 右操作数       |
| ------------- | ---------- | -------------- |
| $h\cdot y$    | 稠密多项式 | $\omega$       |
| $h\cdot r_2$  | 稠密多项式 | $\omega_{r,e}$ |
| $s\cdot r_2$  | 稠密多项式 | $\omega_{r,e}$ |
| $u\cdot y$    | 稠密多项式 | $\omega$       |
| $h\cdot r_2'$ | 稠密多项式 | $\omega_{r,e}$ |
| $s\cdot r_2'$ | 稠密多项式 | $\omega_{r,e}$ |
